做一个 **ZenithProxy 自动附魔模块**，能够全自动循环执行以下流程：

1. 去经验农场吸经验，直到达到配置的等级
2. 从装备箱子取出待附魔的装备
3. 从附魔书箱子取出合适的附魔书（智能匹配）
4. 自动寻找并使用铁砧，将装备和附魔书合成
5. 将附魔完成的成品放入成品箱子
6. 重复循环，直到装备或附魔书用完

------

## ⚙️ 配置项

- **装备箱子坐标列表**（多个箱子，逐个扫描）
- **附魔书箱子坐标列表**（多个箱子，逐个扫描）
- **成品存放箱子坐标列表**（成品统一存储，可做负载均衡）
- **经验农场位置**（站位点）
- **铁砧查找**：不配置坐标，在周围范围内自动搜索最近的铁砧

------

## 🧩 功能细化

### 1. 装备获取

- 从配置的装备箱子列表中按顺序查找
- 只取出未附魔或需要进一步附魔的装备

### 2. 附魔书获取（智能匹配）

- 从配置的附魔书箱子中取出可与装备匹配的附魔书
- 匹配逻辑：
  - 判断装备类型（剑/铠甲/镐…）
  - 检查装备现有附魔
  - 配置策略 根据装备类型配置附魔列表

### 3. 经验获取

- 前往配置的经验农场坐标
- 等待直到经验等级 ≥ 配置的等级
- 若经验不足则持续等待/挂机吸经验

### 4. 自动铁砧合成

- 在玩家周围查找铁砧（搜索范围可配置，比如 5~10 格）
- 打开铁砧界面
- 放入装备 + 书 → 合成 → 取出成品

### 5. 成品存储

- 将合成后的装备放入配置的成品箱子列表中
- 如果一个箱子满了，则切换下一个成品箱子

### 6. 循环执行

- 判断条件：
  - 若装备箱子和附魔书箱子都有存货 → 继续循环
  - 若缺少装备或书 → 模块暂停
- 循环模式：直到资源耗尽
