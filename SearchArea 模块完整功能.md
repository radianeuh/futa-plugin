SearchArea 模块完整功能
     
  一、模块概述
     
自动区块加载/搜索模块，用于配合 [ElytraFlyModule.java](src\main\java\com\github\futa\module\ElytraFlyModule.java) ，通过预定义路径自动遍历区域加载区块。

---
  二、架构设计

所有类放一个文件里， 内部类

  SearchArea (主模块)
  ├── SearchAreaModes (枚举: Rectangle, Spiral)
  ├── SearchAreaMode (基类)
  │   ├── Rectangle (矩形模式)
  │   └── Spiral (螺旋模式)
  └── PathingData (路径数据基类)
      ├── PathingDataRectangle
      └── PathingDataSpiral

  设计模式：策略模式 + 工厂模式

  四、核心算法

  4.1 矩形模式 (Rectangle)

  路径规划算法：锯齿形遍历（蛇形） (Zig-zag / Boustrophedon)

  起始点 ───────────────────────► 目标X
     │                              │
     │    ◄─────────────────────    │
     │                              │
     │    ─────────────────────►    │
     │                              │
     ▼ (Z轴方向按rowGap移动)

  状态机：
  ┌─────────────────────────────────────┐
  │  goingToStart = true                │
  │  └─ 玩家移动到起始点 currPos        │
  └──────────────┬──────────────────────┘
                 │ 到达起始点(距离<5)
                 ▼
  ┌─────────────────────────────────────┐
  │  mainPath = true                   │
  │  └─ 水平移动 (±X方向)              │
  └──────────────┬──────────────────────┘
                 │ 到达X边界
                 ▼
  ┌─────────────────────────────────────┐
  │  mainPath = false                  │
  │  └─ 垂直移动 (±Z方向)              │
  │     移动 rowGap * 16 块            │
  └──────────────┬──────────────────────┘
                 │ 完成垂直移动
                 ▼
           返回 mainPath = true

  核心逻辑 (onTick 方法)：
  1. 每 10 分钟自动保存进度
  2. 若 goingToStart：玩家转向并移动到 currPos
  3. 到达起始点后，打印预估完成时间
  4. 根据 yawDirection 前进：

    - -90°：向 +X 方向
    - 90°：向 -X 方向
    - 0°：向 +Z 方向
    - 180°：向 -Z 方向
  5. 到达边界时切换方向

  完成判断：玩家与目标点距离 < 20 块

---
  4.2 螺旋模式 (Spiral)

  路径规划算法：向外扩展的正方形螺旋

          ┌───────────────┐
          │               │
     ┌────┘               └────┐
     │                          │
     │      玩家起始点 ●        │
     │                          │
     └────┐               ┌────┘
          │               │
          └───────────────┘

  扩展规则：
  - 每次转弯 90°
  - 水平移动 blockGap + spiralWidth 后转弯
  - 垂直移动 blockGap + spiralHeight 后转弯
  - 每次转弯后更新对应的 spiralWidth/spiralHeight

  状态机：
  mainPath = true (水平移动)
      │
      │ 到达 X 轴边界
      ▼
  mainPath = false (垂直移动)
      │
      │ 到达 Z 轴边界
      ▼
  mainPath = true (继续水平，螺旋扩大)

---
  五、数据持久化

  保存格式：JSON

  PathingDataRectangle 结构：
  {
    "initialPos": {"x": 0, "y": 64, "z": 0},
    "currPos": {"x": 100, "y": 64, "z": 200},
    "yawDirection": -90.0,
    "mainPath": true,
    "targetPos": {"x": 500, "y": 64, "z": 500},
    "lastCompleteRowZ": 180
  }

  PathingDataSpiral 结构：
  {
    "initialPos": {"x": 0, "y": 64, "z": 0},
    "currPos": {"x": 100, "y": 64, "z": 200},
    "yawDirection": -90.0,
    "mainPath": true,
    "spiralWidth": 192,
    "spiralHeight": 192
  }

  保存时机：
  - 模块停用时
  - 每 10 分钟自动保存

  文件位置：  search-area/{save-name}/{mode}.json

  六、关键方法

     调用

```
var rotation = RotationHelper.rotationTo(x, 0, z);
INPUTS.submit(InputRequest.builder()
        .owner(this)
        .yaw(rotation.getX())
        .priority(10000)
        .build());
```

来转向朝着目标点， 由ElytraFlyModule自动飞行到达目标点.

有对应的config 和 command 类

  七、流程图

  ┌──────────────────────────────────────────────────────────────┐
  │                     SearchArea 激活                          │
  └─────────────────────────┬────────────────────────────────────┘
                            │
                            ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  检查是否有保存的 JSON 文件                                   │
  │  ├─ 有 → 加载路径数据                                        │
  │  └─ 无 → 创建新路径数据                                      │
  └─────────────────────────┬────────────────────────────────────┘
                            │
                            ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  onTick() 每 tick 执行                                       │
  │  ├─ 1. 自动保存检查（每10分钟）                               │
  │  ├─ 2. goingToStart ? → 移动到起始点                         │
  │  ├─ 3. 到达起始点 → 开始搜索                                  │
  │  └─ 4. 按路径移动，根据边界条件转向                            │
  └─────────────────────────┬────────────────────────────────────┘
                            │
                            ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  模块停用 / 完成路径                                          │
  │  ├─ 保存当前进度到 JSON                                       │
  │  └─ 可选：断开服务器连接                                      │
  └──────────────────────────────────────────────────────────────┘
